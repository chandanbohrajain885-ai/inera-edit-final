Real-face lip-sync (your own face)

For a video of your real face speaking any audio, use the free Colab notebook: it runs LatentSync 1.5 on Google's free T4 GPU. Upload a short clip (or photo) of yourself and your recorded voice (or the voice created here).

  • No API key and no payment — needs only a Google account for Colab.
  • Typical speed on a free T4: about 1–3 minutes per 10 seconds of video.
  • The result is labelled “AI-generated” on screen and in the file.
  • Licence: LatentSync is Apache-2.0, but the face detector it downloads (InsightFace) is for non-commercial use — see the notebook.
  • Honest status: follows LatentSync's official scripts; not verified on a GPU by the builder.
Open Google Colab
In Colab: File → Upload notebook → choose the downloaded file → Runtime → Run all.
